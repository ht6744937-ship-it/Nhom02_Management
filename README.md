# Pet Management System

Pet Management System - Group Project

## Project Structure

- `frontend/` - Frontend web application
- `backend/` - Backend/API
- `database/` - Database files
- `docs/` - Project documents

## Team Workflow

1. Get the latest code before working.
2. Put frontend code in `frontend/`.
3. Put backend code in `backend/`.
4. Put SQL/database files in `database/`.
5. Put project documents in `docs/`.
6. Commit and push your changes regularly.
